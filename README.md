# Sistema Element Sound — página de apresentação

Página pública do **Sistema Element Sound**, aplicativo Windows de gestão para
oficina de eletrônica automotiva: ordens de serviço, **cobrança integrada à
maquininha da Vero**, pagamento em partes, catálogo com leitor de código de
barras, orçamento e recibo em PDF, estoque, financeiro, folha de pagamento e
sincronização entre computadores.

**https://mikerock12.github.io/element-sound/**

## Parceria Vero · Banrisul Pagamentos

A Smells Like Tech Informática é parceira da **Vero**, a maquininha da Banrisul
Pagamentos, e a integração do sistema pelo **Vero Cliente PDV** foi homologada por
ela. O valor vai do sistema direto para a maquininha — Banricompras à vista,
parcelado e pré-datado, Crédito 1 Minuto, débito, crédito à vista e parcelado,
Pix, Vero Wallet e voucher —, a venda só fecha quando o pagamento é aprovado, e o
comprovante fica guardado na ordem de serviço.

## O que este repositório contém

Apenas a página de apresentação do produto — um `index.html` e as imagens das
telas, feitas com uma oficina de demonstração: **todos os nomes, placas,
telefones, CNPJs e comprovantes nas imagens são fictícios.**

**O código-fonte do sistema não está aqui e não é público.** O Sistema Element
Sound é software proprietário, licenciado e entregue instalado ao cliente, com
suporte. Este repositório existe para hospedar a página, nada além disso.

## Tecnologia do produto

C# · .NET 10 · WPF · SQLite · Vero Cliente PDV · Firebase Authentication e Cloud
Firestore · MigraDoc e PDFsharp · xUnit · Inno Setup.
